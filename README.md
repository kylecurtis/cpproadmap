## Key Features

- 📴 **Free & Open Source**: 100% free. Forever open source.
- 🏠 **Local-first & offline**: Always available. No internet required.
- 🔮 **Future-focused**: Tracks modern C++ and evolves with the standard (C++11/14/17/20/23/26 and beyond).
- 🧭 **Structured path optional**: A main() to mastery route exists, but the map is yours to explore.
- 🧠 **Second brain / compendium**: A living reference, not a frozen tutorial.
- 🗺️ **Roadmap, not a rail**: Follow the suggested path or explore on your own through the ever-changing C++ landscape.

## How to Use

![Obsidian Tested Badge](https://raw.githubusercontent.com/kylecurtis/cpproadmap/refs/heads/main/00-assets/badges/project/obsidian-tested-badge.svg)

C++ Roadmap is currently created and tested with [Obsidian](https://obsidian.md/), making it the recommended platform for this project. Obsidian is:

- Fully cross-platform (Windows/Mac/Linux).
- Highly customizable.
- Available on mobile (allowing information to always be accessible).
- Locally functional, without requiring an internet connection.

## Vault Setup (Obsidian)

### 1. Clone the Repository:

```sh
git clone https://github.com/kylecurtis/cpproadmap.git
```

or [download the zip](https://github.com/kylecurtis/cpproadmap/archive/refs/heads/main.zip)

### 2. Set up the vault (Obsidian)
   
- On your computer, open Obsidian (or open a new Obsidian window if already open). 
- Click the `Open` button next to `Open folder as vault`.
- Find and select the unzipped repository directory you just cloned or downloaded in step 1.
- With the project now open, find and open the `roadmap` file in the root directory to get started.

For more information visit [Create vault from an existing folder](https://obsidian.md/help/manage-vaults#Create+vault+from+an+existing+folder)

## Alternative Options

If Obsidian is not your preferred solution, this project should not slow you down while using alternatives. Between CommonMark formatting, and restrictions around any external or 3rd-party plugins, this project should be compatible with any markdown rendering software.

> That being said, please don't submit any issue you encounter as a result of using an unsupported platform unless you are certain the issue is caused by this project.
